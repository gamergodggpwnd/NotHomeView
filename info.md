# NotHomeView

[![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=gamergodggpwnd&repository=NotHomeView&category=plugin)

Apple‑HomePad‑style frosted‑glass cards for Home Assistant: 22 NotHomeView cards (Home Screen, thermostat, lights, scenes,
music / Now Playing, TV, calendar, camera, battery, people, garage chooser, screensaver settings, edit button and more), each
with a visual editor. New in 1.30.7: Night / Day / Auto theme for the device pages.

Requires **Wallpanel**, **card-mod** and **browser_mod**; optional: kiosk-mode, button-card, layout-card, auto-entities. The matching **HomeView Glass / Light** themes (card‑mod), the style helper and example
dashboards are in the repository (`themes/`, `button_card_templates/`, `examples/`); see the README for setup.
