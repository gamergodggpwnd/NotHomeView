# NotHomeView

[![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=gamergodggpwnd&repository=NotHomeView&category=plugin)

Apple‑HomePad‑style frosted‑glass cards for Home Assistant: 14 NotHomeView cards (thermostat, lights, scenes, music /
Now Playing, camera, battery, people, screensaver settings, edit button and more), each with a visual editor and a Size
dropdown.

Needs **browser_mod** for the popups. The matching **HomeView Glass / Light** themes (card‑mod), the style helper and example
dashboards are in the repository (`themes/`, `button_card_templates/`, `examples/`); see the README for setup.
